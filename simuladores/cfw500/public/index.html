Tags da IHM

Endereços no padrão do protocolo, começando em 0. A coluna Ref. mostra a referência “Modicon” (ex.: Holding Register 0 = 400001) que alguns softwares usam. Coil e Discrete Input são sempre BOOL.

Como ligar no CODESYS (mapa padrão)

  1. Em Ethernet do CLP adicione ModbusTCP Slave Device (servidor). Porta 502, Unit ID 1. Ative as áreas de bit (Coils e Discrete Inputs, ≥ 3 cada) e deixe Holding Registers ≥ 1 e Input Registers ≥ 2.
  2. No I/O Mapping do Slave Device, ligue as variáveis: Coils e Holding Registers chegam como entradas do CLP (%IX / %IW, a IHM escreve); Discrete Inputs e Input Registers saem como saídas do CLP (%QX / %QW, a IHM lê). Se o mapeamento recusar o tipo (UINT/INT num canal WORD), declare a variável como WORD e converta no programa (WORD_TO_UINT, INT_TO_WORD…).
  3. No mesmo Ethernet, o Scanner EtherNet/IP com o CFW500 (EDS): saída palavra 1 = P0684, palavra 2 = P0685; entrada palavra 1 = P0680, palavra 2 = P0681.
  4. No inversor: P0220 = 1, P0222 = 11, P0226 = 9, P0227 = 4 (aba CLP virtual → "Parametrizar inversor para comando via rede").
  5. Para mostrar a corrente: P0820 = 3 (3ª palavra de leitura = P0003), P0849 = 1 e entrada do scanner com 3 palavras.
