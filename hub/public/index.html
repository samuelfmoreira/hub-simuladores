    Adicionar e atualizar

    Um .zip de simulador novo entra na bancada; um .zip de simulador que já existe vira atualização.

      Como funciona a atualização

      1. O HUB para o simulador, se ele estiver aberto.
      2. A versão atual vai para a pasta backups (ficam as 3 últimas de cada simulador).
      3. A versão nova entra no lugar, mantendo os seus dados: parâmetros salvos, câmeras, configurações.
      4. As dependências só são baixadas de novo se o package.json mudou.

      Para voltar uma versão, abra o simulador na Bancada e use Versões anteriores.

      Criar um simulador novo

      Siga o contrato do HUB: a ficha simulador.json e as variáveis SIM_IP e SIM_HTTP_PORT.
